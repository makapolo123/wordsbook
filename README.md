# 单词熟练度记忆辅助程序

本项目是一个使用 Python 和 Tkinter 构建的桌面单词背诵工具，提供简洁的学习概览、专注复习、可搜索词库和学习记录页面。每个单词记录自己的**记忆强度**（即“多久之后该复习”）：只有到期的词才会被抽到，逾期越久优先级越高；答对后间隔按增长系数拉长，答错后骤减并降低增长系数，因此复习次数多、记得牢的词很少再出现，难记词则会自动获得更频繁的复习。熟练度由记忆强度换算，全部单词达标后完成背诵，进度自动保存到本地，复习数据也会记录保存。

<br>

## 主要功能

1. 支持导入 txt 文本批量添加单词，自动去除重复单词
2. 单词熟练度区间为 50-100，熟练度达到 90（记忆强度约 90 天）视为掌握完毕，之后不再抽取
3. 记忆强度调度：每个词有独立的复习间隔，答对后从 0.5 天起步逐次增长（约 ×2.5，上限 390 天），只有到期后才重新出现
4. 到期词之间按“逾期倍数”加权：拖得越久的词越优先；逾期倍数封顶后权重相同，保证公平轮换、不会有词一直抽不到
5. 同一个词 12 小时内不会被重复抽到；没有到期单词时会提示最近一次的到期时间
6. 难记词自动加成：答错会同时降低记忆强度和增长系数，之后复查更频繁
7. 图形化答题：首屏提供“认识 / 不认识”，选择“认识”后进入释义页，并提供“下一个 / 记错了 / 记住了”三个后续选项；作答后直接进入下一个单词
8. 全程自动保存背诵进度，关闭程序进度不会丢失
9. 自动记录每次复习的统计数据和每个单词的复习明细
10. 提供单词搜索、状态筛选、近 7 天复习量图表和最近复习明细

<br>

## 项目文件介绍

- words_book.py      程序主运行代码
- words_book_gui.py  图形界面代码
- words.txt          存放需要背诵的单词文本
- words.json         自动生成，储存每个单词的熟练度、记忆强度、增长系数和复习时间
- words.json.bak     旧存档迁移前自动生成的备份（迁移时可用来回退）
- statistic_data.txt 自动生成，追加保存每次复习的统计数据
- word_record.csv    自动生成，追加保存每个单词的复习明细
- README.md          项目说明文档
- docs/              **手机网页版（PWA）**，纯静态，可直接部署到 GitHub Pages
- tools/             开发辅助脚本（算法对照测试、图标生成），不参与部署

<br>

## 单词书写格式

words.txt内每行填写一组单词，英文和中文释义用逗号隔开

示例：

- apple, 苹果
- banana, 香蕉
- teacher, 老师
- book, 书本

<br>

## 运行方法

1. 电脑提前安装 Python 3.7 及以上版本
2. 打开项目文件夹，修改 words.txt 添加自己需要背诵的单词
3. 运行 `python words_book.py` 启动图形界面

如需继续使用原来的控制台模式，可运行：

```bash
python words_book.py --cli
```

如果使用的是旧版 words.json，第一次启动会自动按历史复习记录迁移记忆强度，并生成 words.json.bak 备份。

## 手机 / 网页版

`docs/` 是一份与桌面版共用同一套记忆算法和存档格式的网页应用，可以装到手机主屏，全屏运行、离线可用。

访问地址：<https://makapolo123.github.io/wordsbook/>

### 首次使用

1. 电脑上把 `words.json`（如需带明细再加 `word_record.csv`）通过微信文件传输助手、网盘等方式发到手机
2. 手机浏览器打开上面的链接 → 点「选文件导入」→ 选择刚收到的文件
3. 导入成功首页会显示词库总数和掌握进度，核对无误后点浏览器的「添加到主屏幕」

iPhone 用 Safari 打开后点「分享 → 添加到主屏幕」；安卓在 Chrome 菜单里选「安装应用」。

### 复习手势

复习页以上滑为主操作，手指按住卡片往上划，松手即生效：

| 当前画面 | 上滑结果 |
| --- | --- |
| 正面单词 | 显示释义 |
| 释义页 | 答对并进入下一个单词 |
| 已判定后 | 继续下一个单词 |

滑动距离不足会自动弹回，不会误触。页面上只保留三个纠错按键——「不认识」「记错了」「记住了」，样式刻意做得很轻，不与词义抢注意力。桌面浏览器也可以用鼠标按住卡片上拖，或按 `↑` 键。

### 数据存放

手机端的词库存 `localStorage`，复习明细存 `IndexedDB`，都只在本机，不经过任何服务器。因此：

- 换手机、清空浏览器数据前，先在「学习记录 → 导出备份」里导出一份
- iOS 对长期不访问的站点可能清理存储，装到主屏并定期导出可避免
- 导出的 `words.json` 字段与桌面版完全一致，可以直接覆盖电脑上的同名文件；`word_record.csv`、`statistic_data.txt` 同理

### 本地调试

```bash
# 在项目根目录启动，之后浏览器打开 http://localhost:8000/docs/
python -m http.server 8000
```

`localhost` 属于安全上下文，Service Worker 能正常注册，可在开发者工具里验证离线缓存。

## 界面使用说明

左侧导航包含三个页面：

1. **今日学习**：查看到期单词数、掌握进度、熟练度分布和最近到期时间，从这里开始复习
2. **单词库**：搜索单词或按“待复习 / 新词 / 已掌握”筛选，也可以直接导入新的 TXT 词表
3. **学习记录**：查看累计复习量、记住率、近 7 天复习量以及最近的答题明细

<br>

## 背诵页面操作说明

抽取的单词都是已经到期的词。看到英文单词后有两个选项：

1. `1 认识`：进入释义页，然后选择“下一个 / 记错了 / 记住了”
2. `2 不认识`：直接记录为答错，显示释义后点击“下一个单词”继续

选择“认识”后：

1. `1 下一个`：回答正确，保存后直接显示下一个单词
2. `2 记错了`：回答错误，保存后直接显示下一个单词
3. `3 记住了`：熟练度标记为 101，保存后直接显示下一个单词，之后不再复习

右上角“结束本轮”也可以随时返回首页，同时保存进度并写入本次复习统计。

> 手机网页版以手势为主：上滑查看释义，再上滑进入下一个。页面上只留「不认识 / 记错了 / 记住了」三个纠错键，并刻意做成弱样式。下面的数字键在电脑浏览器上仍然可用。

复习页支持键盘操作：

- 未显示释义时：`1` 认识，`2` 不认识
- 显示释义后：`1` 下一个，`2` 记错了，`3` 记住了
- 完成一题后：`Enter` 或空格进入下一个单词

答错之后记忆强度会骤减，因此这个词很快又会到期，需要重新巩固。
没有到期单词时，复习页会提示最近一次的到期时间，避免把还不需要复习的词反复抽出来。

## 自定义设置参数

可直接修改代码开头常量调整数值：

存档与记录文件：

- WORDS_SAVE_FILE —— 单词数据本地保存文件（words.json）
- STATISTIC_FILE —— 复习统计数据文件（statistic_data.txt）
- RECORD_DATA_FILE —— 单词复习明细文件（word_record.csv）

熟练度参数：

- STD_PRO —— 达标的熟练度标准（90，约等于 90 天记忆强度）
- MAX_PRO —— 最大熟练度（100，对应记忆强度上限）
- MIN_PRO —— 最小熟练度（50，从未复习或刚答错）

记忆强度参数（决定每个词多久复习一次）：

- MIN_STABILITY_DAYS —— 记忆强度下限，单位天（0.25，约 6 小时）
- INIT_STABILITY_DAYS —— 首次答对后的记忆强度（0.5 天）
- MAX_STABILITY_DAYS —— 记忆强度上限（390 天，对应熟练度 100）
- STABILITY_FAIL_FACTOR —— 答错时记忆强度乘以的系数（0.4）
- EASE_DEFAULT —— 增长系数初始值（2.5）
- EASE_MIN / EASE_MAX —— 增长系数下限 / 上限（1.3 / 3.0）
- EASE_UP / EASE_DOWN —— 答对时增长系数增加量 / 答错时减少量（0.1 / 0.2）
- MIGRATE_MAX_STABILITY_DAYS —— 旧存档迁移时记忆强度的上限（14 天）

抽取策略参数：

- NEW_POOL_RATIO —— 新词池抽取占比，剩余概率给复习池，0~1（0.5）
- DUE_THRESHOLD —— 逾期倍数达到多少才算到期，1 表示正好到计划复习时间（1.0）
- MIN_REVIEW_GAP_HOURS —— 同一个词两次抽取的最小间隔小时数（12）
- LATENESS_CAP —— 逾期倍数上限，超过后权重不再增加，保证公平轮换（2.0）
- LATENESS_POWER —— 逾期倍数权重指数，越大越偏向拖延久的词（2）

<br>

## 附加说明

1. 熟练度由记忆强度换算（对数映射）：0.25 天对应 50，90 天对应 90（达标），390 天对应 100；选择“记住了”时为特殊值 101
2. 所有单词熟练度大于等于 90 时，程序自动结束背诵
3. 抽取只看“是否到期”：逾期倍数 = 距上次复习时间 ÷ 记忆强度，达到 1 才算到期，不到期不会出现
4. 同一个词 12 小时内不会被重复抽到；到期词之间权重按逾期倍数计算，达到 LATENESS_CAP 后权重相同，所以不会有词一直抽不到
5. 答对时记忆强度乘以增长系数，越熟练间隔越长（0.5 天 → 1.25 天 → 3 天 → 8 天 → …），每天需要复习的量会随熟练度提高而下降；答错时记忆强度骤减、增长系数降低，难记词因此自动复查更频繁
6. 旧版存档会自动迁移：按 word_record.csv 的顺序回放每个词的历史对错，换算出初始记忆强度（上限 14 天），迁移前自动备份为 words.json.bak
7. 每个单词记录 en、cn、proficiency、stability、ease、first_review、last_review、fail_count、success_count 字段；旧版存档会自动补齐字段
8. 图形界面会自动刷新学习状态，并在每次答题后保存进度；控制台模式仍可通过 `--cli` 使用
