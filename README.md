# 单词熟练度记忆辅助程序

本项目使用Python编写控制台单词背诵工具，依据单词复习时间间隔和单词熟练度分配出现频率，不熟的单词会短时间多次弹出复习，全部单词熟练度达标后完成背诵，背诵进度自动保存本地，背诵的数据也会记录保存。

<br>

## 主要功能

1. 支持导入txt文本批量添加单词，自动去除重复单词
2. 单词熟练度范围50-100，熟练度达到90视为掌握完毕
3. 单词抽取规则：在复习时间间隔内，熟练度越低，被抽取复习的概率越高，时间间隔随熟练度动态变化
4. 答题操作选项： 
    - 认识单词：熟练度增加 
    - 不认识单词：熟练度降低 
    - 记错单词：熟练度降低 
    - 单词已记牢：熟练度达标
5. 全程自动保存背诵进度，关闭程序进度不会丢失

<br>

## 项目文件介绍

- words_book.py  程序主运行代码
- words.txt    存放需要背诵的单词文本
- words.json   自动生成，储存单词熟练度进度
- README.md    项目说明文档

<br>

## 单词书写格式

words.txt内每行填写一组单词，英文和中文释义用逗号隔开

示例：

- apple, 苹果
- banana, 香蕉
- teacher, 老师
- book, 书本

<br>

## 运行方法

1. 电脑提前安装Python3.7及以上版本
2. 打开项目文件夹，修改words.txt添加自己需要背诵的单词
3. 运行words_book.py启动程序

<br>

## 程序菜单使用说明

1. 导入单词txt文件
2. 开始单词背诵复习
3. 退出程序

<br>

## 背诵页面操作指令

1. 选择认识单词
    - 下一个单词
    - 记错单词
    - 单词已记牢
2. 选择不认识单词
3. 退出背诵页面

<br> 

## 自定义设置参数

可直接修改代码开头常量调整数值：

- SAVE_FILE ——单词数据本地保存文件
- STATISTIC_FILE ——复习数据文件
- RECORD_DATA_FILE ——复习的单词数据文件
- STD_LINE ——达标的熟练度标准
- MAX_PRO ——最大熟练度
- MIN_PRO ——最小熟练度
- ADD_POINT ——认识单词增加的熟练度数值
- SUB_POINT ——不认识单词扣除的熟练度数值

<br>

## 附加说明

1. 熟练度最高100，最低50，不会超出区间
2. 所有单词熟练度全部大于等于90，程序自动结束背诵
3. 空白输入、错误输入均会提示重新输入，程序运行稳定
