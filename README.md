# 单词熟练度记忆辅助程序

本项目使用 Python 编写的控制台单词背诵工具。它依据单词熟练度和复习时间间隔进行分层加权抽取：不熟的单词出现频率更高，熟练度越高复习间隔越长；同时加入遗忘衰减和难记词加成。全部单词熟练度达标后完成背诵，进度自动保存到本地，复习数据也会记录保存。

<br>

## 主要功能

1. 支持导入 txt 文本批量添加单词，自动去除重复单词
2. 单词熟练度区间为 50-100，熟练度达到 90 视为掌握完毕
3. 分层加权抽取：新词与待复习词按固定比例分配，池内熟练度越低概率越高，复习间隔随熟练度指数增长
4. 每过一段时间会按未复习天数自然降低熟练度，新学的单词首次复习后也容易回退
5. 难记词（历史错误率高）会被额外加权，复习次数太少的词不参与判定
6. 答题操作选项：
    - 认识单词：熟练度增加
    - 不认识单词：熟练度降低
    - 记错单词：熟练度降低
    - 单词已记牢：标记为特殊值，之后不再出现
7. 全程自动保存背诵进度，关闭程序进度不会丢失
8. 自动记录每次复习的统计数据和每个单词的复习明细

<br>

## 项目文件介绍

- words_book.py      程序主运行代码
- words.txt          存放需要背诵的单词文本
- words.json         自动生成，储存单词熟练度进度（每个单词一条记录）
- statistic_data.txt 自动生成，追加保存每次复习的统计数据
- word_record.csv    自动生成，追加保存每个单词的复习明细
- README.md          项目说明文档

<br>

## 单词书写格式

words.txt内每行填写一组单词，英文和中文释义用逗号隔开

示例：

- apple, 苹果
- banana, 香蕉
- teacher, 老师
- book, 书本

<br>

## 运行方法

1. 电脑提前安装 Python 3.7 及以上版本
2. 打开项目文件夹，修改 words.txt 添加自己需要背诵的单词
3. 运行 words_book.py 启动程序

<br>

## 程序菜单使用说明

1. 导入单词 txt 文件（输入文件名，如 words.txt）
2. 开始背诵复习
3. 退出程序（保存进度）

<br>

## 背诵页面操作指令

输入 `1`（认识）并看到释义后，可继续选择：

1. `1` 下一个：熟练度 +10（上限 100）
2. `2` 记错了：熟练度 -8（下限 50）
3. `3` 记住了：熟练度标记为 101，之后不再抽取

其他指令：

- `2` 不认识：直接显示释义，熟练度 -8（下限 50）
- `0` 退出背诵：保存进度并退出，同时写入本次复习统计

<br> 

## 自定义设置参数

可直接修改代码开头常量调整数值：

存档与记录文件：

- WORDS_SAVE_FILE —— 单词数据本地保存文件（words.json）
- STATISTIC_FILE —— 复习统计数据文件（statistic_data.txt）
- RECORD_DATA_FILE —— 单词复习明细文件（word_record.csv）

熟练度参数：

- STD_PRO —— 达标的熟练度标准（90）
- MAX_PRO —— 最大熟练度（100）
- MIN_PRO —— 最小熟练度（50）
- ADD_POINT —— 认识单词增加的熟练度数值（10）
- SUB_POINT —— 不认识/记错单词扣除的熟练度数值（8）

抽取策略参数：

- NEW_POOL_RATIO —— 新词池抽取占比，剩余概率给复习池，0~1（0.5）
- WEIGHT_POWER —— 熟练度权重指数，越大越偏向低熟练度的词（3）
- COOLDOWN_MIN_HOURS —— 最低复习间隔小时数，对应最低熟练度（0.25）
- COOLDOWN_MAX_HOURS —— 最高复习间隔小时数，对应最高熟练度（24.0）
- OVERDUE_FLOOR —— 刚复习过的词的权重系数下限（0.05）
- OVERDUE_CAP —— 逾期很久的词的权重系数上限（3.0）

难记词加成参数：

- HARD_RATE_THRESHOLD —— 错误率低于该值不算难记词，权重不受影响（0.25）
- HARD_BOOST —— 错误率每超出阈值 0.05，权重就多 0.5 倍（10.0）
- HARD_CAP —— 难记加成倍率的上限（4.0）
- HARD_MIN_REVIEWS —— 复习次数少于该值不做难记判定（4）

<br>

## 附加说明

1. 熟练度做加减时限制在 50-100 区间；标记"记住了"时为特殊值 101，不参与抽取
2. 所有单词熟练度全部大于等于 90 时，程序自动结束背诵
3. 距上次复习每满一天，熟练度会自然下降（下降量随时间递增，且记录在 last_reduce 中避免重复扣减）
4. 新词首次复习后 1 天内若熟练度达标，会被回退到 82，以强化记忆
5. 每个单词记录 en、cn、proficiency、first_review、last_review、last_reduce、fail_count、success_count 字段；旧版存档会自动补齐字段，并从 word_record.csv 回填历史对错次数
6. 空白输入、错误输入均会提示重新输入，程序运行稳定
